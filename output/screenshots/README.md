## 개인정보 가림

**저장소가 public이다.** 두 장은 가림 처리를 거쳐서 들어갔다.

| 파일 | 가린 것 |
|---|---|
| `02-start-learning.png` | 웹캠 미리보기에 찍힌 얼굴 |
| `04-mypage.png` | 좌상단 사용자 실명 |

가림은 픽셀화 + 블러라 복원되지 않는다. **가리지 않은 원본을 이 폴더에 두지 않는다** —
한 번 커밋되면 히스토리에 남는다.
