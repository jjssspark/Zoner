## 찍을 때

- 다크 단일 테마이므로 한 벌만 찍으면 된다
- 브라우저 창은 1440px 폭 기준. 개발자도구는 닫고 찍는다
- 실명·이메일 등 개인정보가 화면에 있으면 가린다 (저장소가 public이다)
- 로딩·측정 중 같은 중간 상태도 하나는 남긴다. 그것도 설계의 일부다
