원본 화질본(`demo.mp4`, 1440×748 · 30fps · 4.3MB)은 **저장소에 넣지 않는다.**
`.gitignore`로 제외돼 있다 — 히스토리에서 뺄 수 없는 크기의 바이너리를 쌓지 않으려고
외부 호스팅(YouTube)에 올리고 링크로 건다.

원본 녹화는 3420×1948 / 60fps / 3분 10초. 18개 구간으로 나눠 1~10배속을 따로 걸었다.
**측정 대기처럼 화면이 안 변하는 구간만 10배속**이고, 자리비움 알림이 뜨는 순간과
영상 저장 확인 대화상자는 등속으로 뒀다 — 기능을 보여주는 장면이라서다.

## 개인정보 가림

**저장소가 public이다.**

| 파일 | 가린 것 |
|---|---|
| `02-start-learning.png` | 웹캠 미리보기에 찍힌 얼굴 |
| `04-mypage.png` | 좌상단 사용자 실명 |
| `demo.gif` · `demo.mp4` | 로그인 화면의 이메일 입력란과 브라우저 자동완성 드롭다운 |

**영상은 얼굴을 가리지 않는다.** 스크린샷과 방침이 다르다 — 사람이 앉아 있는 화면을
보여주는 게 이 제품의 설명에 필요하다고 판단했다. 가리는 것은 타인의 정보와 계정 식별자뿐이다.

가림은 블러라 복원되지 않는다. **가리지 않은 원본을 이 폴더에 두지 않는다** —
한 번 커밋되면 히스토리에 남는다.

### 영상에서 잘라낸 것

가리는 것보다 **빼는 것이 안전한 구간**은 편집에서 제외했다.

| 원본 구간 | 무엇이 있었나 |
|---|---|
| 43.5~47.5초 | Discord 창 — 친구 목록 실명·닉네임·프로필 사진, Notion 작업 노트 |
| 116~125.5초 | 흰 화면 + 확대된 macOS Dock (메시지·카카오톡 알림 배지 수치) |
| 39.5~42초 | macOS 창 정렬 메뉴 — 연결된 모니터 모델명 |
| 화면 하단 전 구간 | macOS Dock — 설치 앱 구성과 알림 배지 (1948→1776 크롭) |
| 174초 이후 | 이미 보여준 화면 반복 |

**완성본을 1초 간격 프레임으로 전부 훑어 확인**했다. 이 검사에서 잡힌 것:
저장 확인 대화상자를 잡았다고 생각한 구간이 실제로는 대화상자가 뜨기 **직전**이었고
(99.3초에 뜬다), 리포트 진입 직전에 빈 흰 화면 2초가 남아 있었다.
