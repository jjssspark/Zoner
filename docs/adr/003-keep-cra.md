# ADR-003 — CRA를 유지하고 Vite로 이전하지 않는다

**날짜** 2026-08-05 · **상태** 채택 (부채로 등록) · **관련** [ADR-005](005-ci-false-over-craco.md)

## 맥락

프로젝트는 `create-react-app`으로 시작했다. `react-scripts` 5.0.1은
**공식적으로 유지보수가 멈춘 상태**다. 새 기능도, 의존성 업데이트도 오지 않는다.

작업 기간은 2026-08-04 ~ 08-11, 8일이었다. 그 안에 측정·리포트·채팅·휴지통·녹화·PDF를
전부 만들어야 했다.

## 선택지

| 안 | 얻는 것 | 드는 것 |
|---|---|---|
| A. Vite 이전 | 개발 서버 기동·HMR 속도, 살아 있는 생태계 | 빌드 설정, 테스트 러너(Jest→Vitest), 환경변수 prefix(`REACT_APP_`→`VITE_`), `public/` 처리, 전 화면 회귀 확인 |
| B. CRA 유지 | 시간 | 멈춘 의존성, 알려진 리졸버 제약 |
| C. Next.js | SSR, 라우팅 | 이 앱에 SSR이 필요 없다. 웹캠은 어차피 클라이언트에서만 돈다 |

## 결정

**B — CRA를 유지하고, 부채라는 사실을 README의 "알려진 한계"에 명시한다.**

C는 빠르게 탈락했다. 이 앱의 핵심 화면(측정)은 `getUserMedia`와 WASM에 묶여 있어
서버 렌더링으로 얻을 게 없다.

## 근거

**이전으로 얻는 것이 사용자에게 닿지 않는다.** Vite의 이득은 대부분 개발 경험이다.
빌드 산출물은 지금도 gzip 기준 메인 청크 JS 150.78 kB(코드 분할 청크까지 더하면 약 198 kB) /
CSS 11.8 kB로 나쁘지 않다.
8일짜리 일정에서 사용자가 못 보는 개선에 하루를 쓸 수 없었다.

**이전은 "설정만 옮기는" 작업이 아니다.** 테스트 러너를 바꾸면 22개 스위트 276개 테스트가
전부 검증 대상이 된다. 환경변수 prefix가 바뀌면 배포 설정도 같이 바뀐다.
그 과정에서 회귀가 나면 기능 작업이 멈춘다.

**부채는 갚지 않아도 되지만, 숨기면 안 된다.** README에 적어 두면 그건 "모르고 방치한 것"이
아니라 "알고 미룬 것"이 된다. 포트폴리오에서 그 차이가 크다고 봤다.

## 대가

**이 결정의 비용이 실제로 두 번 청구됐다.**

**① 테스트 전략이 통째로 바뀌었다** (TROUBLESHOOTING.md TS-003).
CRA 번들 Jest 리졸버가 `react-router-dom` v7의 exports 맵을 해석하지 못한다.
그래서 **`react-router-dom`을 import 하는 파일에는 테스트를 쓸 수 없다.**

이 제약이 코드 구조를 바꿨다. 판단이 들어간 순수 로직은 `src/lib/`으로,
라우터에 의존하지 않는 프레젠테이션 컴포넌트는 `src/components/ui/`로 내려갔다.
결과적으로 관심사 분리는 좋아졌지만, **그건 설계 판단이 아니라 도구 제약이 밀어낸 결과**다.
그리고 화면 단위 E2E가 없다는 공백이 남았다.

**② 첫 배포가 즉시 깨졌다** (TS-020).
CRA는 `CI=true`를 보면 경고를 에러로 승격한다. 배포 환경은 그 변수를 자동으로 건다.
승격된 경고가 하필 `@mediapipe/tasks-vision`에서 나와서 우리 코드로는 손댈 수 없었다 →
[ADR-005](005-ci-false-over-craco.md).

## 결과

**판단 자체는 유지한다.** 8일 안에 기능을 완성한다는 목표는 달성했고,
Vite로 갔다면 그 시간이 어디선가 빠졌을 것이다.

**다만 "비용이 나중에 온다"를 과소평가했다.** 이전을 미룬 대가가 개발 서버가 조금 느린 것
정도일 줄 알았는데, 실제로는 테스트 범위와 배포 성공 여부에 왔다.
멈춘 도구의 비용은 속도가 아니라 **"막혔을 때 고칠 방법이 없다"**로 나타난다.

되돌리는 조건: E2E 테스트를 도입하거나 `react-router-dom`을 올릴 때.
그때는 리졸버 제약이 다시 걸리므로 이전이 미루는 것보다 싸진다.
